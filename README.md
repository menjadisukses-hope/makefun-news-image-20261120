# The World Today — 20 November 2026 in one image

Entry for make.fun bounty **news-image-20261120**: "Sum up 20 November's world news in one image" ($250, 50 places paid, deadline 22 Nov 2026 00:00 UTC / 07:00 WIB).

## What it does
`main.py` (Python 3.13) copies `news.png` to `/output/entry.png`. No network; repeated runs produce identical bytes. Image: 1024×1024 PNG, ~194 KB (limit: 1 MiB).

`generate.py` is the deterministic Pillow program that drew `news.png` from the headlines below.
